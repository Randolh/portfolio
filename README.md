# Portafolio Estatico - Desarrollador Full-Stack

Este repositorio contiene el codigo fuente de mi portafolio web personal. El proyecto fue construido bajo la premisa de crear una interfaz moderna y completa utilizando estrictamente HTML y CSS puro, demostrando dominio sobre el diseño web sin depender de lenguajes de scripting o librerias de terceros.

## Caracteristicas Principales

*   Cero JavaScript: Toda la interactividad de la pagina se maneja a traves de CSS avanzado.
*   Modo Claro y Oscuro: Implementado nativamente usando selectores de estado de CSS y variables en la raiz para una transicion fluida.
*   Navegacion estilo macOS: Menu inferior fijo con animaciones de escalado basadas puramente en transformaciones y transiciones CSS.
*   Diseño 100% Responsivo: Adaptable a multiples dispositivos (movil, tablet y escritorio) utilizando Flexbox, CSS Grid y Media Queries bajo un enfoque Mobile First.
*   Alta Compatibilidad: Estructurado semanticamente para ser renderizado sin problemas en entornos MCP (Model Context Protocol), como Google Stitch o Antigravity.

## Arquitectura y Metodologia

El codigo CSS y la estructura HTML siguen estrictamente la metodologia BEM (Block, Element, Modifier). Esto asegura que los estilos sean modulares, encapsulados y altamente escalables, evitando colisiones de clases y facilitando la inyeccion de componentes dinamicos desde un backend si se requiere en el futuro.

## Tecnologias Utilizadas

*   HTML5 (Semantico)
*   CSS3 (Variables, Flexbox, Grid, Animaciones)

## Instrucciones de Uso

Dado que es un proyecto completamente estatico, no requiere instalacion de dependencias ni ejecucion de servidores locales.

1.  Clona este repositorio en tu maquina local.
2.  Abre la carpeta del proyecto.
3.  Haz doble clic en el archivo `index.html` para abrirlo en cualquier navegador web moderno.
